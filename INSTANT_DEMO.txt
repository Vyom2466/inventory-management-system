        TROUBLESHOOTING
================================================================

Backend shows error?
→ Make sure you ran "npm install" in backend folder

Port already in use?
→ Kill process or change port in server-demo.js

Still shows login page?
→ Make sure backend is in demo mode (npm run demo)
