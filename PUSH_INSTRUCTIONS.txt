================================================================
        HOW TO PUSH TO GITHUB - SIMPLE GUIDE
================================================================

OPTION 1: AUTOMATIC (EASIEST)
------------------------------
1. Double-click: PUSH_TO_GITHUB.bat
2. Follow the prompts
3. Done!


OPTION 2: MANUAL COMMANDS
--------------------------

Step 1: Open Terminal (Command Prompt or PowerShell)
----------------------------------------------------
Press Windows Key + R
Type: cmd
Press Enter


Step 2: Navigate to Project
---------------------------
cd C:\Users\vyom\OneDrive\Desktop\baroda_project\inventory-management-system


Step 3: Run These Commands One by One
-------------------------------------

git init

git add .

git commit -m "Initial commit: Complete Inventory Management System"


Step 4: Create GitHub Repository
--------------------------------
1. Open browser: https://github.com/new
2. Repository name: inventory-management-system
3. Click "Create repository"
4. Copy the repository URL (looks like):
   https://github.com/YOUR_USERNAME/inventory-management-system.git


Step 5: Link and Push
--------------------
Replace YOUR_USERNAME with your GitHub username:

git remote add origin https://github.com/YOUR_USERNAME/inventory-management-system.git

git branch -M main

git push -u origin main


================================================================
        WHAT YOU'LL NEED
================================================================

✅ Git installed (download from: https://git-scm.com)
✅ GitHub account (create at: https://github.com/signup)
✅ Internet connection


================================================================
        AUTHENTICATION
================================================================

If asked for password, use Personal Access Token:

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name: Inventory Management System
4. Check: repo
5. Click "Generate token"
6. Copy the token
7. Use as password when pushing

================================================================
        QUICK TROUBLESHOOTING
================================================================

Problem: "git: command not found"
Solution: Install Git from https://git-scm.com

Problem: "Permission denied"
Solution: Use Personal Access Token instead of password

Problem: "remote origin already exists"
Solution: Run: git remote remove origin
          Then add it again

Problem: "Repository not found"
Solution: Check the URL is correct
